## 1. 产品概述与范围

### 1.1 一句话

个人**离线**记账 App，Flutter 实现，**只做 Android**。核心链路：记一笔 → 按月看账 → 导入第三方账单 → 看统计/预算/资产。

### 1.2 范围内（已确认）

| 项 | 结论 |
|---|---|
| 平台 | **Android**（无 Mac，iOS 不做，架构上不预留障碍） |
| 技术栈 | Flutter 3.47.2 / Dart 3.13.2 + drift 2.31.0 + Riverpod 3 + go_router 18 |
| 数据来源 | 手工记账 + 微信 xlsx / 支付宝 CSV 导入 |
| 验收设备 | MuMu 12 模拟器（A 机，`emulator-5554`） |

### 1.3 范围外（已确认不做）

- iOS 构建 · 云同步（`identity` / `sync`）· 旧 App 数据迁移工具（手工重建账本）
- **支付相关 API**（ADR-6）· 预算提醒/系统推送 · 记一笔的「转账」写入口（`transfer` 只读）
- 旧栈 T2.8 真机复验（用户未答复，按「不做」处理）

## 2. 术语与通用口径（跨模块一致，改动需重签字）

| 术语 | 口径 |
|---|---|
| **金额** | 一律 `INTEGER` **整数分**（ADR-2）；展示用 `centsToYuan`（千分位 + 两位小数）；输入正则 `^\d+(\.\d{1,2})?$`，**不允许负数** |
| **删除** | **永不物理删除**（ADR-3），一律写 `deleted_at` 软删；所有查询默认排除 |
| **主键 / 同步元数据** | 客户端 UUID v4（ADR-1）；每张业务表带 `id / owner_id / created_at / updated_at / deleted_at / dirty` |
| **当前账本** | `activeBookIdProvider` 持久化；除管理页外，**所有跨页数据都按当前账本隔离** |
| **月份不能超当前月** | 首页 hero、日历、统计的翻月共同受此约束（`canGoNext`）；预算例外——历史月可补设、未来月可预设 |
| **「当月」定义** | 真实当前月份，不是用户正在看的月份 |
| **支出 / 收入配色** | 中国习惯：**支出红 / 收入绿**（与 `summarize`、统计、日历一致） |
| **主题** | 深色：底 `#0C0C0C` + 琥珀橙 `#FFAF38` |
| **各页月份状态独立** | 首页 / 日历 / 统计 / 预算各自记月份；写操作后统一由 **`dataEpochProvider` bump** 触发重算 |
| **入账幂等** | ADR-7：`source` + `fingerprint` 部分唯一索引，导入一律走 `importTransaction()` |

## 4. 数据模型

`schemaVersion = 2`（`lib/core/db/`）。**改 `tables.dart` 必须重跑 `dart run build_runner build`**，产物 `database.g.dart` 一并入库。

| 表 | 关键字段 | 说明 |
|---|---|---|
| `books` | name, sort | 账本，切换即数据隔离边界 |
| `accounts` | book_id, name, type, initial_balance_cents, **icon, color（未启用）** | 账户；资产页数据源 |
| `categories` | name, type, icon, preset | 预置不可删 |
| `transactions` | book_id, account_id, category_id, type, amount_cents, note, occurred_at, source, fingerprint, **transfer_group_id（预留，无方向语义）** | 流水主表 |
| `budgets` | book_id, period('YYYY-MM'), amount_cents | **v2 新增**，部分唯一索引 |
| `schema_meta` | key, value | KV 元数据（含 `active_book_id`） |

索引：**表结构由 drift 声明式生成，索引一律原始 SQL**（ADR-9，`@TableIndex` 表达不了 `DESC` 与部分索引）。v1 有 7 条，v2 追加 1 条。
