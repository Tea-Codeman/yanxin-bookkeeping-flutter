## 5. 走查抓到的问题

### 🔴 1. 未滑开时红色动作区「透」出行（已修）

- **现象**：首版每行右侧**一直**露出一段红色 + 「垃圾桶 / 删除」——不用滑就能看到，视觉上像「已经滑开了」。
- **根因**：`TxTile` 自身**没有背景色**（行的白来自外层白卡 `Container(decoration: cardDeco())`），
  而 `SwipeActionRow` 的 `Stack` 底层钉着红色动作区 → 行是透明的，红底直接透出来。
- **修法**：`Transform.translate` 内给行包一层 `ColoredBox(color: Tok.paper)`
  （`lib/features/ledger/presentation/widgets/swipe_action_row.dart`），并留注释说明「行必须自带不透明底」。
- **复验**：修复后重启截图，首页 / 日历页未滑开时右侧干净 ✅（见 `.workbuddy/shots/07-home-fixed.png`）。
- ⚠️ **这个 bug 只有真机能抓到** —— widget 测试断言的是「结构 / 行为」，看不出「颜色透过」。

### ⚠️ 2. 装包后立即注入 adb 输入可能不生效（环境坑，非代码问题）

- **现象**：`install -r` + 启动后，`input tap`（点底栏 tab）与 `input swipe`（左滑行）**全部无反应**，
  但 UI 正常渲染（状态栏时钟在走）、`pidof` 有进程、`logcat -b crash` 为空。
  只有 `uiautomator` 语义树能抓到节点（说明 App 活着）。
- **处置**：`am force-stop` + 重新 `monkey` 启动后**立即恢复正常**（之后所有 tap/swipe 都生效）。
- **结论**：环境侧偶发（MuMu 输入通道 / 首次启动窗口未就绪），**不是 F7.8 的代码问题**；
  以后走查若遇到「点了没反应」，先重启 App 再判定。
